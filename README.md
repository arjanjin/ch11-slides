## การใช้งาน

| ปุ่ม | ทำอะไร |
|---|---|
| → / Space / Enter / คลิกด้านขวา | สไลด์ถัดไป |
| ← / Backspace / คลิกด้านซ้าย | สไลด์ก่อนหน้า |
| F | เต็มจอ |
| Home / End | สไลด์แรก / สุดท้าย |
| ปัดซ้าย–ขวา | เลื่อนสไลด์บนมือถือ/แท็บเล็ต |

ลิงก์ไปสไลด์ที่ต้องการได้ด้วยเลขหน้าท้าย URL เช่น `…/#24`
